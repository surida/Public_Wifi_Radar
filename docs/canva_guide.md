# Canva - App Store 스크린샷 제작 가이드 🎨

Canva(캔바) 무료 버전을 사용하여 고퀄리티 스크린샷을 만드는 방법입니다.

## 1. 캔버스 설정 (Create Design)
1.  [Canva.com](https://www.canva.com/) 접속 및 로그인
2.  우측 상단 **'디자인 만들기 (Create a design)'** 클릭
3.  **'사용자 지정 크기 (Custom size)'** 클릭
4.  **1290 x 2796 px** 입력 후 '새로운 디자인 만들기' 클릭

## 2. 기본 요소 배치 (Layout)

### 배경 (Background)
1.  좌측 **'요소 (Elements)'** 탭 클릭 → '사각형 (Square)' 도형 선택
2.  도형을 캔버스 전체 크기로 확대
3.  상단 **색상(Color)** 아이콘 클릭
4.  **'+' 버튼(새 색상 추가)** 클릭 → **'그라데이션(Gradient)'** 탭 선택
5.  아래 [디자인 스펙](#3-디자인-스펙-design-specs)의 컬러 코드를 입력하여 색상 설정

### 디바이스 프레임 (Device Frame)
1.  **'요소 (Elements)'** 탭 → 검색창에 **"iPhone 14 frame"** 또는 **"Phone mockup"** 검색
2.  **'프레임 (Frames)'** 섹션에서 원하는 휴대폰 모양 선택 (이미지를 넣을 수 있는 구름 그림이 있는 것)
3.  화면 하단 중앙에 적절한 크기로 배치

### 스크린샷 넣기 (Upload)
1.  좌측 **'업로드 (Uploads)'** 탭 → **'파일 업로드'** 클릭
2.  가지고 있는 앱 스크린샷 파일(`screenshots/en/...`, `screenshots/ko/...`) 선택
3.  업로드된 이미지를 **드래그**하여 방금 배치한 휴대폰 프레임 안으로 **쏙** 넣기

### 텍스트 (Text)
1.  좌측 **'텍스트 (Text)'** 탭 → **'제목 추가 (Add a heading)'** 클릭
2.  상단에 배치하고 아래 [디자인 스펙](#3-디자인-스펙-design-specs)의 문구 입력
3.  **폰트**: 'Gothic', 'Noto Sans KR', 'Black Han Sans' 등 두꺼운 고딕체 추천
4.  **효과(Effects)**: 상단 '효과' 클릭 → **'그림자(Shadow)'** 또는 **'테두리(Outline)'** 적용 (가독성 UP!)

## 3. 디자인 스펙 (Design Specs)

### 1장: Main Feature (Hero)
*   **배경색**: `#00FFFF` (Cyan) ↔ `#FFDC00` (Yellow)
*   **제목**: 터치 한 번으로\n와이파이 찾기! 🎉
*   **소제목**: 내 주변 무료 와이파이 즉시 검색
*   **이미지**: `screenshots/en/screentshot_appstore_eng.png`

### 2장: Coverage
*   **배경색**: `#8C00FF` (Purple) ↔ `#FF64C8` (Pink)
*   **제목**: 서울부터 부산까지\n전국 어디서나 📡
*   **소제목**: 데이터 걱정 없이 마음껏!
*   **이미지**: `screenshots/ko/screenshot_appstore_6.7_클러스터링.png`

### 3장: Benefit
*   **배경색**: `#003296` (Navy) ↔ `#00C8C8` (Teal)
*   **제목**: 여행 필수품!\n끊김 없는 여행 ✈️
*   **소제목**: 복잡한 로그인 없이 바로 연결
*   **이미지**: `screenshots/ko/screenshot_appstore_6.7_마커클릭.png`

---

### 4장: Free & No Login (텍스트 강조형)
*   **배경색**: `#00C850` (Green) ↔ `#0080FF` (Blue)
*   **제목**: 100% 무료!\n로그인 필요 없음 🆓
*   **소제목**: 개인정보 걱정 없이 바로 사용
*   **이미지 대신**: **큰 아이콘** (자물쇠 🔒, 방패 🛡️, 또는 선물 상자 🎁)을 중앙에 배치하세요.
    *   Canva '요소' 탭에서 "Lock 3D", "Shield 3D", "Free 3D" 검색

---

## 4. 내보내기 (Export)
1.  우측 상단 **'공유 (Share)'** 클릭
2.  **'다운로드 (Download)'** 클릭
3.  파일 형식: **PNG**
4.  **'다운로드'** 버튼 클릭

이제 App Store Connect에 업로드하시면 됩니다! 🚀
